# 🥟 Jajanan Puanmuda — Landing Page & Digital Menu

> **"Cemilan Kekinian — Cobain sekarang, dijamin ketagihan!"**  
> Landing page resmi dan etalase digital pemesanan kuliner **Jajanan Puanmuda** yang berlokasi di Suela, Lombok Timur, Nusa Tenggara Barat.

---

## 🌟 Fitur Utama

- **Desain Modern & Responsif:** Desain kaya visual mengadaptasi palet khas merah marun (`#B3121B`), kuning kunyit (`#FFC62B`), dan krem hangat (`#FAF3E3`).
- **Etalase Menu Digital:** Katalog aneka Dimsum Mentai, Risol (Mayo, Bolognase, Ayam Suwir), Mie Jebew, Burger, dan Es Teler lengkap dengan filter kategori & pencarian.
- **Keranjang Belanja Real-Time:** Tersimpan di local storage pengguna, mendukung pengaturan kuantitas, catatan per item, dan pilihan metode Ambil/Antar.
- **Kalkulator Ongkir Otomatis:** Perhitungan ongkir otomatis untuk area Suela & wilayah Lombok Timur serta promo Gratis Ongkir belanja di atas Rp100.000.
- **Format Pesanan WhatsApp Otomatis:** Checkout langsung membuka WhatsApp bisnis (`0819 2803 4054`) dengan rekap pesanan rapi.
- **Modul Pre-Order & Katering Acara:** Formulir khusus pemesanan snack box rapat, hampers, dan paket arisan.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router + Turbopack)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Typography:** Google Fonts (`Fredoka`, `Poppins`, `Caveat`)
- **Language:** TypeScript

---

## 🚀 Memulai (Local Development)

Pastikan Node.js (v18+) sudah terpasang di komputer Anda.

```bash
# Clone repositori
git clone https://github.com/aztaga456/jajanan-puanmuda.git
cd jajanan-puanmuda

# Install dependensi
npm install

# Jalankan server pengembangan
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser untuk melihat hasilnya.

---

## 📦 Build Produksi

```bash
npm run build
npm start
```
